# PentePula

Site do salão de beleza infantil PentePula, pronto para GitHub + Netlify.

## Estrutura
- `index.html` — página principal
- `style.css` — identidade visual e responsividade
- `script.js` — serviços, profissionais e agendamento
- `assets/logo/` — coloque aqui a logo oficial
- `assets/profissionais/` — coloque aqui as fotos dos profissionais
- `assets/imagens/` — outras imagens do site
